# Web Awesome 3.12.0 coverage evidence

User constraint (2026-09-07): no purchased controls. Pro entries below remain catalog facts only and are excluded from usable coverage. In particular, searchable Combobox is a gap in the eligible Web Awesome offering; Data Grid and Video are also unavailable for our selection. No Pro package was purchased or installed.

Research dates: 2026-09-06/07. Root-reviewed correction of a partial delegated draft. Scope: map the complete inventory in [component-library-candidates.md](component-library-candidates.md) to Web Awesome 3.12.0, without adoption. Sources: [catalog](https://webawesome.com/docs/components), component docs, [Core license](https://webawesome.com/license), [Pro license](https://webawesome.com/license/pro), [package registry](https://registry.npmjs.org/@awesome.me%2Fwebawesome).

| Inventory need | Web Awesome 3.12.0 | Availability | Semantic fit and local work |
|---|---|---|---|
| Hierarchical tree/navigation | `wa-tree`, `wa-tree-item` | Core catalog component | Good hierarchy/keyboard surface ([tree docs](https://webawesome.com/docs/components/tree/)); discovery, selection, file/domain commands, loading and persistence remain local. It does not perform file operations. |
| Foldable/split panels | `wa-split-panel` | Core catalog component | Adjacent resizable panes ([docs](https://webawesome.com/docs/components/split-panel)); shell still owns fold/reveal rails, two-panel state, interruption, reduced motion and settled bounds. `wa-drawer` is overlay-only ([docs](https://webawesome.com/docs/components/drawer)) and cannot satisfy the docked requirement alone. |
| Drag/drop targets | No dedicated inventory component | Missing | Local pointer/keyboard reorder, hit testing, domain/file operation semantics and announcements. Do not treat Split Panel or Tree as drag/drop. |
| Buttons/icon buttons | `wa-button`, `wa-icon` | Core catalog component | Commands, loading/disabled and labeled icon-only actions ([button docs](https://webawesome.com/docs/components/button/)); ownership, tooltip policy and shortcuts remain local. |
| Select/searchable combobox | `wa-select`; `wa-combobox` | Select Core stable; Combobox Pro, stable since 3.1 | Select fits fixed choices ([select docs](https://webawesome.com/docs/components/select)); Combobox adds filtering/creation but requires Pro ([combobox docs](https://webawesome.com/docs/components/combobox)). Async/domain behavior remains local. |
| Switches, checkbox/radio | `wa-switch`, `wa-checkbox`, `wa-radio-group` | Core catalog component | Form semantics/keyboard behavior; persistence, rollback and policy remain local ([checkbox docs](https://webawesome.com/docs/components/checkbox/)). |
| Fields/validation | `wa-input`, `wa-textarea`, `wa-number-input` | Core; Number Input stable | Useful labeled fields and constraints; folder picker is an application/Electron adapter, path display and save/error behavior remain local. |
| Dialogs | `wa-dialog` | Core catalog component | Focused confirmation/form surface, Escape/light-dismiss ([dialog docs](https://webawesome.com/docs/components/dialog/)); nested/protected focus and operation policy remain local. |
| Menus/context actions | `wa-dropdown`, `wa-dropdown-item` | Core catalog component | Keyboard navigation, submenus and checkable items are documented ([dropdown docs](https://webawesome.com/docs/components/dropdown)); application command enablement, destructive confirmation and filesystem semantics remain local. |
| Popovers/anchored utilities | `wa-popover`, `wa-popup` | Core catalog component | Anchoring and outside/Escape close fit utilities ([popover docs](https://webawesome.com/docs/components/popover/)); built-in single-popover exclusivity helps, but shell-wide coordination with other utility types, focus policy, history and map content/routing remain local. |
| Tooltips | `wa-tooltip` | Core catalog component | Hover/focus/tap text tooltip with accessible wiring ([tooltip docs](https://webawesome.com/docs/components/tooltip/)); no interactive content or essential-only-on-hover behavior. |
| Status/progress/errors | `wa-progress-bar`, `wa-progress-ring`, `wa-spinner`, `wa-badge`, `wa-callout`, `wa-details` | Core catalog component | Indication/disclosure primitives; Activity and Errors model, retention, retry, copy and keyboard history remain local. |
| Tabs/segmented presentation | `wa-tab-group`, `wa-tab`, `wa-tab-panel` | Core catalog component | Good tab semantics and arrow activation ([tab group docs](https://webawesome.com/docs/components/tab-group/)); must not replace app-screen registration or routing. |
| Virtualized lists/grids | `wa-data-grid` | Pro, experimental since 3.11 | Claims table/tree-data/selection/virtualization ([data grid docs](https://webawesome.com/docs/components/data-grid/)); not a mounted-video-grid replacement. Identity, playback and domain layout remain local. |
| Keyboard-command surface | `wa-dialog`/`wa-popover` + `wa-details`, `wa-copy-button` as primitives | Core primitives | Can host the read-only help surface; it does not route shortcuts, define active-screen descriptors, keycap presentation, focus policy or remapping. |
| Media-editor primitives | `wa-slider` (including range), `wa-progress-*`; `wa-video` | Slider/progress Core stable; Video Pro, experimental since 3.7 | Slider supports numeric/range selection ([slider docs](https://webawesome.com/docs/components/slider/)); useful visual primitive only. `wa-video` is paid/experimental ([catalog](https://webawesome.com/docs/components)); it cannot own canonical frame identity, prepared-review timing, extraction or audio policy. |
| Scroll/disclosure | `wa-scroller`, `wa-details` | Core catalog component | Basic scroll/disclosure; Activity’s hidden-scrollbar, Arrow/Page/Home/End navigation, overflow cue and technical-error semantics remain local. |

License boundary: the installed Core package declares MIT. Pro requires separate paid access and a component/asset license check before adoption; no Pro package was purchased or installed. Component availability does not establish icon/font redistribution rights.

Verification: all 17 original inventory rows are mapped. Root spot-checks of official Combobox, Number Input, Data Grid, Video, Tree, Popover, Dropdown and Slider pages corrected three draft errors: Combobox and Number Input are stable, and Data Grid is experimental since 3.11 (not 3.6). Other basic entries are catalog coverage, not an individually tested stability/accessibility assertion. Live docs describe the current catalog; Core implementation evidence is pinned to installed 3.12.0. Pro runtime behavior was not tested. The delegated task hit a usage limit after writing a partial draft; its original verification claim was not accepted as evidence.

Assessment: broad coverage of ordinary shell controls and the future tree, with normal application-owned composition. Searchable combobox is the meaningful paid boundary. Drag/drop and our specialized media/grid behavior remain local; the Pro data grid and video player do not remove those responsibilities. The shell still needs screen registration, command routing, persistence, activity/error state and cross-surface focus coordination. This catalog assessment does not override the panel motion failure in the evaluation report.
